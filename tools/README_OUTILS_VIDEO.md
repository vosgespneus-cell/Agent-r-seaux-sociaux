# Boîte à outils vidéo VOSGES PNEUS

## QMM AutoEdit
Outil CPU pour transformer des rushs en Shorts/Reels/TikTok : suppression des silences, recadrage vertical 9:16, sous-titres mot par mot et sélection d'un passage dynamique.

Installateur : `INSTALL_QMM_AUTOEDIT_WINDOWS.bat`

Dépôt amont : https://github.com/respectfulnrespected59-source/qmm-autoedit

## Utilisation prévue
1. filmer Adam ou l'atelier avec le téléphone
2. nettoyer automatiquement les silences
3. recadrer en 9:16
4. générer les sous-titres localement
5. assembler avec les plans premium générés dans le cloud
6. ajouter vraie voix, logo et appel à l'action
7. exporter MP4 pour TikTok / Facebook / Instagram / YouTube Shorts

## Choix matériel
Le poste actuel n'a pas de GPU NVIDIA. Les outils retenus ici privilégient donc le CPU et FFmpeg plutôt que les gros modèles vidéo génératifs locaux.

## Sécurité
Ne jamais ajouter une clé API, un mot de passe ou un token réel dans ce dépôt.
