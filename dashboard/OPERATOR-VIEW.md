# Vue opérateur

Objectif: comprendre l'état de la machine en moins de 10 secondes.

En haut:
MACHINE: OK / ATTENTION / PANNE
Dernière activité
Entrées aujourd'hui
Actions réalisées
Actions qui attendent un humain

Blocs:
1. Urgent
2. Clients à rappeler/répondre
3. Rendez-vous
4. Commandes
5. Publications
6. Erreurs techniques

Chaque ligne doit montrer:
heure | origine | résumé | agent | état | prochaine action

L'opérateur ne voit pas les détails techniques par défaut.

Boutons prévus:
VALIDER
CORRIGER
RELANCER
PRENDRE EN MAIN
VOIR JOURNAL

Aucune manipulation GitHub ou terminal nécessaire pour l'opérateur final.
